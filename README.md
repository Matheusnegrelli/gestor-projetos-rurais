# Gestor de Projetos Rurais com IA

Sistema web para pequenos produtores rurais planejarem e acompanharem projetos da propriedade (escopo, tarefas, cronograma, custos e riscos) com apoio de Inteligência Artificial.

Projeto de extensão do curso de Sistemas de Informação (UNESC Colatina, 2026), tema "Inteligência Artificial como Apoio ao Gerenciamento de Pequenos Projetos".

- **Site:** https://matheusnegrelli.github.io/gestor-projetos-rurais/
- **Banco de dados:** Supabase (plano gratuito), tabela `registros` (ver `supabase_setup.sql`)
- **IA:** Google Gemini (chave gratuita configurada em ⚙ IA, salva só no navegador). Sem chave, os planos usam modelos padrão por cultura.
